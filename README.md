# 🏪 Cartly E-Commerce Frontend

A modern, responsive React e-commerce UI built with **Vite** for fast development and optimized production builds. Features product browsing, cart management, checkout, and order tracking.

---

## ✨ Features

- ✅ **Product Catalog** – Browse all products with responsive grid layout
- ✅ **Search & Filter** – Real-time product search with 500ms debounce
- ✅ **Shopping Cart** – Add/remove items, manage quantities, view totals
- ✅ **Checkout Flow** – Select delivery options, review order, apply taxes
- ✅ **Order History** – View all past orders with dates and totals
- ✅ **Order Tracking** – Real-time delivery tracking with estimated arrival dates
- ✅ **Responsive Design** – Mobile-first, works on all screen sizes
- ✅ **Fast Development** – Vite with Hot Module Replacement (HMR)
- ✅ **Error Handling** – Graceful error pages and fallbacks

## 🚀 Quick Start

### Prerequisites
- **Node.js** v14 or higher
- **npm** or yarn
- **Backend server** running on `http://localhost:3000`

### Installation

```bash
# Navigate to frontend folder
cd ecommerce-project

# Install dependencies
npm install

# Start dev server
